# 루틴 플레이어

개인용 자기관리 루틴 플레이어. 유튜브 구간 반복 + 타이머 + 시작음/종료음, 맨몸 근력 체크, 복근 운동, 기록 그래프.

- 루틴 추가·수정: `index.html` 상단 `ROUTINES` 배열만 고치면 됨
  - 실행형: `videoId`, 단계별 `t`(시작초)·`end`(끝초), `mode: "reps"|"time"`, `reps`/`sec`, `sets`, `labels`, `cue`
  - 가이드형: 단계별 `name`, `body`

## 앱으로 설치 (PWA)
- 삼성 폰: 크롬 또는 삼성 인터넷에서 열고 홈 화면의 "📲 홈 화면에 설치" 버튼, 또는 메뉴 → 앱 설치/홈 화면에 추가
- 아이패드: Safari 공유 버튼(□↑) → 홈 화면에 추가
  - 설치한 앱은 Safari와 저장 공간이 따로라서, Safari에서 쓰던 기록은 "기록 보내기 → 기록 합치기"로 옮겨야 함
- `sw.js`(서비스 워커)가 앱 화면을 저장해 두어 오프라인에서도 열림. 유튜브 영상만 인터넷 필요(오프라인이면 영상 없이 타이머만 진행)
- 업데이트: 온라인이면 열 때마다 최신 `index.html`을 받아옴(네트워크 우선). `sw.js`를 바꿀 땐 `VERSION`을 올리기

## 기기 간 기록 합치기
- 홈 맨 아래 "기기 간 기록 옮기기"
  - 보내기: 파일 공유(카톡 나에게·드라이브·AirDrop) 또는 코드 복사
  - 합치기: 받은 파일 고르기 또는 코드 붙여넣기
- 병합 규칙: 날짜·루틴·운동별로 합치고, 같은 칸이 양쪽에 있으면 더 많이 한 쪽(d가 큰 쪽)을 남김 → 여러 번 넣어도 중복 없음
- 설정(`cfg_*`, `absv`, `tempo` 등)은 기본적으로 이 기기 것을 유지하고 없는 것만 채움. 체크하면 상대 기기 설정으로 맞춤
